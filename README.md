# To-Do List App
A simple command-line To-Do application built with python

## Decription
This project allows users to mannage their daily tasks through an interactive menu.
users can add, view, complete, and delet tasks.

## Features
1. Add new tasks
2. Display all tasks with numbered lists
3. Mark tasks as compleated using a [Done] label
4. Delete tasks by their numbers
5. Handle non-numeeric input using exception handling
6. Display a message when the task list is empty
7. Exit the application

## Technologies
Python 3

## How to Run
1. Make sure python 3 is installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command: python main.py
